# Index

Generated by tools/check-modules --write from the module headers. Do not edit by
hand.

Match the task against the "Load when" lines below. Say which module applies and
read it. Then read its overlay, the file in $OVERLAY_DIR with the module's file
name, such as apply-patches.md, if it exists. The overlay wins on conflict. When
a step links to a module from the module's Depends on field, read that module
too. $ALIASES maps the user's short names to modules.

Modules that $MODULES does not enable do not apply. If a step needs one, tell
the user. If a task needs a parameter the profile leaves unset and it has no
default, ask the user. Never guess it.
